# Oasis Infobyte Internship - Web Development (OIBSIP)

## Overview
This repository contains the task submissions for the Web Development and Designing internship at Oasis Infobyte[cite: 1, 3]. These projects were developed to complete the Level 2 track requirements, focusing on front-end architecture, responsive design, and state management using HTML5, CSS3, and Vanilla JavaScript[cite: 6, 8, 9].

## Projects Included
*   **Task 1: Calculator (`/WebDev-L2-Calculator`)**
    A fully functional browser-based calculator built with a CSS Grid layout[cite: 9, 10]. It handles basic arithmetic operations, supports sequential operator chaining, and includes specific edge-case error handling to prevent application crashes during division by zero[cite: 10].
*   **Task 2: Tribute Page (`/WebDev-L2-TributePage`)**
    A responsive webpage dedicated to Malala Yousafzai[cite: 10]. It features a clean user interface spanning a structured biography, a timeline of key achievements, and distinct typographical styling using paired Google Fonts[cite: 10].
*   **Task 3: To-Do Web App (`/WebDev-L2-ToDoApp`)**
    An interactive task management application that allows users to add, edit, delete, and mark tasks as complete[cite: 11]. It features dynamically updating task count indicators, distinct pending and completed lists, and relies on `localStorage` to ensure data persists across browser reloads[cite: 11].
*   **Task 4: Login Authentication System (`/WebDev-L2-LoginSystem`)**
    A client-side authentication flow featuring user registration and secure login validation to guard a protected dashboard page[cite: 11, 12]. The system enforces strict password validation, checks for duplicate user registrations, and utilizes the Web Crypto API for client-side password hashing[cite: 11].

## Installation & Usage
1. Clone this repository to your local machine:
   `git clone https://github.com/laseyae07-cmd/OIBSIP.git`
2. Navigate into the repository and select a specific project directory (e.g., `cd WebDev-L2-Calculator`)[cite: 4].
3. Open the `index.html` file in any modern web browser to run the application locally[cite: 10].
