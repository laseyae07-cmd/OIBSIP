# Simple Web Calculator

A web-based calculator application built with core frontend web technologies.

## Features

* **Mathematical Operations**: Performs basic arithmetic including addition, subtraction, multiplication, and division.


* **Input Controls**: Features a Clear (C) button to reset the display and a Delete (DEL) button to remove the last entered character.


* **Error Prevention**: Automatically detects division by zero attempts and outputs an "Error" message.


* **Responsive Layout**: Designed with a CSS Grid structure for the keypad and CSS Flexbox to center the calculator perfectly on the user's screen.



## Technologies Used

* **HTML**: Defines the core structure, utilizing data attributes to manage operator inputs.


* **CSS**: Handles the visual presentation, featuring a dark mode aesthetic with specific color coding: orange for operators, red for clear, and green for equals.


* **JavaScript**: Manages all interactive logic, dynamically updating the DOM and evaluating equations using a strict `Function` constructor rather than `eval()`.



## Project Files

* `index.html`: The main document that structures the display interface and button grid.


* `style.css`: The styling rules that give the calculator its dimensions, grid layout, and visual theme.


* `script.js`: The application logic that processes button clicks, strings together equations, and calculates the final output.



## How to Run

1. Clone this repository to your local computer.
2. Open the project folder.
3. Double-click the `index.html` file to open it in your default web browser.
