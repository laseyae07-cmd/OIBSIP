# Malala Yousafzai - Tribute Page

A responsive tribute page built for Oasis Infobyte Web Development (Level 2).

## Files
- `index.html` - structure and content
- `style.css` - layout, colours, fonts, responsive rules
- `script.js` - image fallback, expandable timeline, active nav link
- `malala-image.jpg` - **add this yourself** (see below)

## Adding the image
1. Find a royalty-free photo on Wikimedia Commons or Unsplash and check its licence.
2. Save it as `malala-image.jpg` next to `index.html`.
3. Update the photo credit in the `<figcaption>` in `index.html`.

## Features
- Title with name and one-line tagline
- Prominent framed portrait
- "At a glance" fact cards
- Four-paragraph biography with subheadings
- Styled featured quote plus "In her words" quote cards
- Timeline of key achievements: ordered list of expandable cards
- "Her Message" and "Legacy" sections
- Backgrounds: ink blue, pale blue, off-white, white cards
- Fonts: Fraunces (serif headings), Nunito Sans (sans-serif body)
- Responsive layout, sticky navigation, keyboard focus styles
